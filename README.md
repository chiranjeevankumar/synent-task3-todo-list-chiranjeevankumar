To-Do List Application

Project Description

This is a simple command-line To-Do List application developed using Python. It helps users manage their daily tasks by adding, viewing, and deleting tasks.

Features

- Add new tasks
- View all tasks
- Delete tasks by their task number
- Menu-driven interface
- Simple and beginner-friendly Python code

Technologies Used

- Python 3

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

python todo_list.py
